## Fixed

- Brief machine reconnects no longer immediately make Power, Status, and water/grounds readings unavailable. The integration keeps the last readings visible for up to 90 seconds after the last successful ready update.
- Longer outages still mark the machine unavailable. The Connected diagnostic continues to show the current connection state immediately.
- Power commands are blocked while disconnected; commands are never queued for later replay.

## Updating

Update **Coffee Local** in Home Assistant **Marketplace**, then restart Home Assistant. No Coffee Local Bridge update or configuration change is required.

## Validation

Tested brief disconnects, the 90-second limit, recovery, command rejection while disconnected, and device identity protection in current and upcoming Home Assistant versions.
